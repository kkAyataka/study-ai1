## 取得方法について

`/usage` は Claude Code に組み込まれたコマンドで、Claude からは実行できない。そのため、同じ情報を次の2つから集めた。

1. **プランの使用率とコンテキスト**：デスクトップアプリの使用量 API（`/usage` の使用量カードと同じ値）
2. **トークン数**：このセッションのログ（`~/.claude/projects/-Users-kkayataka-Projects-study-ai1/397ae604-….jsonl`）に記録された API 呼び出しごとの `usage` を、メッセージIDの重複を除いて合計した

`/usage` の画面そのものを残したい場合は、自分で実行した結果をこのファイルの末尾に貼り付けてください。
