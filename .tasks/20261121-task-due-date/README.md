## 流れ

1. `/grill-with-docs` で、grilling スキルと domain-modeling スキルを読み込む
2. 仕様書とデータ処理のコードを読み、今の前提を確認する
3. 期限日の仕様を質問形式で固める（14問、3ラウンド）。決まった用語はその場で GLOSSARY.md に書く
4. データ（バージョン2と、バージョン1からの変換）を TDD で実装する
5. 画面（期限日の入力・変更・解除と、期限切れの赤字）を TDD で実装する
6. 開発サーバーで動作を確認する
7. docs/spec.md を更新し、コミットする

## 結果

- タスクに任意の期限日（日付だけ）を付け、追加するときにも、あとから一覧でも変更・解除できるようになった
- 期限日の翌日になっても未完了のタスクは、タイトルが赤字になる
- 今の localStorage のデータや、これまでのバックアップファイル（バージョン1）も、期限日なしのタスクとして読める
- テスト35本、lint、ビルドがすべて通っている。プッシュはまだしていない
