## アーキテクチャのレビュー

`git log` から、変更が多いのは `src/App.tsx`（7回）と `src/App.test.tsx`（6回）だと分かった。期限日・並び替え・未完了だけ表示のどれもが `App.tsx` に足されていた。`src/` は1,000行足らずだったので、サブエージェントは使わずに全部読んだ。ADR はまだない。

挙げた候補は次の3つ（HTML レポートは OS の一時フォルダに作り、リポジトリには入れていない）。

| # | 候補 | 強さ |
| --- | --- | --- |
| 1 | タスク一覧の module を深くする。タスクの規則・作成順の約束・保存を1つの interface の裏へ | Strong |
| 2 | 一覧の見せ方の module を作る。並び順・絞り込み・0件の文言・期限切れ | Worth exploring |
| 3 | 書き出し・読み込みの module を深くする。`createBackup` の pass-through を吸収する | Speculative |

ユーザーは候補1を選んだ。
